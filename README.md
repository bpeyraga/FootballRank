# FootballRank

Ranking estilo FIFA para el equipo de fútbol: cada uno vota los atributos de los jugadores (Ritmo, Tiro, Pase, Regate, Defensa, Físico) y la app arma los equipos más parejos.

- App publicada: https://claude.ai/artifact/4TVJ3VZCh43ghkJaQxcubm
- Todo está en `index.html` (sin build ni backend). Abierto localmente guarda los datos en el navegador.
