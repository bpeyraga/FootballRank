# FootballRank

Comunidades de fútbol amateur: calificá a tus compañeros al estilo FIFA, convocá partidos y armá equipos parejos.

- App: `web/` (Preact + Vite + Supabase). Producción: https://footbal-rank.vercel.app
- Base de datos: `supabase/migrations/`

## Levantar en local

```
cd web
copy .env.example .env.local   # completar con la URL y la clave anon de Supabase
npm install
npm run dev
```
